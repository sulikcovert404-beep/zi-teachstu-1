# 🤖 بات تلگرام — پلتفرم آموزش هوشمند ایران

mini-service مستقل (Bun) که بات رسمی تلگرام پلتفرم را اجرا می‌کند؛ **بدون هیچ وابستگی npm** — تمام فراخوانی‌های Bot API تلگرام با `fetch` بومی نوشته شده‌اند.

## معماری

```
تلگرام  ⇄  (long-polling getUpdates)  ⇄  این سرویس (پورت 3003)
                                          │
                                          ├── GET /            → health-check  {ok, service, uptime}
                                          ├── هر ۳۰ ثانیه: GET  localhost:3000/api/v1/internal/telegram/config   (X-Bot-Secret)
                                          ├── اتصال حساب:   POST localhost:3000/api/v1/internal/telegram/link    (X-Bot-Secret)
                                          └── APIهای کاربر (Bearer session token):
                                                GET  /api/v1/books
                                                GET  /api/v1/books/{id}
                                                GET  /api/v1/books/{id}/quiz?model=MC|TF|MIXED|SHORT
                                                POST /api/v1/books/{id}/quiz/attempts   {model, answers}
                                                GET  /api/v1/me/points
                                                GET  /api/v1/books/{id}/podcast         (WAV)
                                                GET  /api/v1/books/{id}/summary.docx    (Word)
```

- **فعال‌شدن بدون ری‌استارت:** تا وقتی مدیر توکن بات را در «تنظیمات و اتصال‌ها» ثبت نکرده باشد، سرویس فقط لاگ می‌کند: «توکن بات تنظیم نشده — منتظر تنظیمات مدیر…». با ذخیرهٔ توکن (یا تغییر آن)، سرویس خودکار `deleteWebhook` را صدا می‌زند و نظرسنجی `getUpdates` را آغاز می‌کند.
- **اتصال حساب:** کاربر کد ۶ رقمی را از پروفایل نسخهٔ وب می‌گیرد و در گفتگو می‌فرستد؛ سرویس آن را با `X-Bot-Secret` به اپ اصلی می‌فرستد و session token را (به‌ازای هر chat_id، در Map) کش می‌کند؛ در خطای 401 یک‌بار نشست را تازه می‌کند.
- **آزمون تعاملی:** هر سؤال یک پیام مستقل با دکمه‌های inline است؛ پاسخ‌ها بی‌صدا جمع می‌شوند (روی پیامِ سؤال فقط «پاسخ شما ثبت شد» نمایش داده می‌شود) و **بازگشایی پاسخ‌ها + نمره + امتیاز** در پیام نهایی از `POST …/quiz/attempts` می‌آید. سؤال تشریحی با تایپ متن پاسخ داده می‌شود. جلسهٔ بی‌فعالیت پس از ۱۰ دقیقه پاک می‌شود.
- **Hot-reload:** `bun --hot` → با تغییر `index.ts`، نسل (generation) جدید حلقهٔ نظرسنجی جای نسل قبلی را می‌گیرد، long-pollهای قبلی abort می‌شوند و offset پیام‌ها در `globalThis` حفظ می‌شود (بدون از دست رفتن پیام و بدون تداخل 409 دائمی).

## متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `TELEGRAM_BOT_SECRET` | `aep-internal-bot-secret` | راز مشترک با اپ اصلی (هدر `X-Bot-Secret`) |
| `MAIN_APP_URL` | `http://localhost:3000` | نشانی اپ Next.js (فراخوانی server-to-server در localhost) |

## اجرا

```bash
cd mini-services/telegram-bot
bun run dev          # = bun --hot index.ts
# یا در پس‌زمینه:
nohup bun run dev > bot.log 2>&1 &
curl -s http://localhost:3003/     # {"ok":true,"service":"telegram-bot","uptime":...}
```

لاگ‌ها با پیشوند `[tg-bot]` در کنسول (یا `bot.log`) نوشته می‌شوند.
**توکن بات و توکن نشست کاربران هرگز لاگ نمی‌شوند.**

## قابلیت‌های بات

- `/start` — خوش‌آمد غنی؛ اگر متصل باشد: سلام شخصی‌سازی‌شده + منوی اصلی (reply keyboard) + دکمهٔ «🎓 باز کردن مینی‌اپ» (web_app).
- `📚 کتاب‌خانه` / `/books` — فهرست کتاب‌ها با وضعیت (✅⏳⚠️)، دکمهٔ «🔄 به‌روزرسانی».
- کارت کتاب — وضعیت خلاصه/نمونه‌سؤال/پادکست + بهترین رکورد.
- `📄 خلاصه` — متن HTML چندتکه («…ادامهٔ خلاصه») + دکمهٔ «📥 دریافت نسخهٔ Word» (ارسال `sendDocument`).
- `🎧 پادکست` — ارسال WAV با `sendAudio` (عنوان/اجراکنندهٔ فارسی).
- `✍️ شروع آزمون` — انتخاب مدل (چهارگزینه‌ای/درست-غلط/ترکیبی/تشریحی)، جلسهٔ تعاملی، نتیجه با نمرهٔ فارسی، 🎉 رکورد جدید، ⭐ امتیاز، مرور کامل پاسخ‌ها.
- `⭐ امتیازهای من` / `/points` — مجموع، ۳۰ روز اخیر، ۵ دستاورد آخر با تاریخ شمسی.
- `ℹ️ راهنما` / `/help`، `🎓 باز کردن اپ` / `/app`، `/link` — راهنمای اتصال.
- کد ۶ رقمی → اتصال حساب؛ متن‌های ناشناخته → پیام راهنما؛ خطاها همیشه با پیام فارسی و بدون کرش حلقه.
